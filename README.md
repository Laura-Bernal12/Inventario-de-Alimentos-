# Sistema de Control de Inventario de Alimentos

## 1. Introducción

El Sistema de Control de Inventario de Alimentos es un proyecto web desarrollado con la finalidad de facilitar la administración y el control de los productos alimenticios de una institución.

El sistema busca mantener organizada la información de los alimentos disponibles, permitiendo llevar un mejor control de los productos y sus movimientos dentro del inventario.

## 2. Objetivo general

Desarrollar una aplicación web que facilite la organización y el control de los alimentos de una institución, permitiendo consultar los productos y mantener un registro de sus existencias.

## 3. Descripción del proyecto

El proyecto consiste en una aplicación web orientada a mejorar la administración de los productos alimenticios. Su diseño permite presentar la información de manera organizada y facilitar la consulta de los diferentes apartados del inventario.

La aplicación cuenta con diferentes secciones destinadas al control y seguimiento de los alimentos.

## 4. Módulos del sistema

- **Inicio de sesión:** pantalla de acceso al sistema.
- **Panel de control:** presenta un resumen general del inventario.
- **Catálogo de productos:** permite visualizar los productos alimenticios registrados.
- **Entradas:** sección destinada al registro de los alimentos que ingresan al inventario.
- **Salidas:** sección destinada al registro de los alimentos que se utilizan o retiran.
- **Alertas:** permite identificar productos que requieren atención, como aquellos con existencias bajas o próximos a vencer.

## 5. Características principales

- Organización de la información de los productos.
- Visualización de las existencias del inventario.
- Presentación de registros de entradas y salidas.
- Consulta de información mediante el panel de control.
- Identificación de productos que requieren atención.
- Diseño de interfaces para facilitar la navegación por el sistema.

## 6. Tecnologías utilizadas

- **HTML5:** utilizado para desarrollar la estructura y organizar el contenido de las páginas web.
- **CSS3:** utilizado para aplicar estilos, colores, tamaños y diseños a las diferentes interfaces del sistema.

## 7. Estructura del repositorio

El repositorio está organizado en las siguientes carpetas y archivos:

- **Documentación:** contiene información y documentos relacionados con el proyecto.
- **Inventario:** contiene los archivos correspondientes al sistema de inventario.
- **README.md:** contiene la descripción general y la información del proyecto.

## 8. Ejecución del proyecto

1. Descargar o clonar el repositorio desde GitHub.
2. Descomprimir el proyecto, si se descargó como archivo ZIP.
3. Abrir la carpeta del proyecto.
4. Ubicar el archivo HTML principal.
5. Abrir el archivo en un navegador web para visualizar el sistema.

## 9. Importancia del proyecto

El Sistema de Control de Inventario de Alimentos busca contribuir a una mejor organización de los productos alimenticios de una institución. Su propósito es facilitar la consulta de información y apoyar el control de los alimentos disponibles.
